# Sababa Service

Marketplace for hiring service professionals in Israel: cleaners, handymen ("husband for an hour"), construction, and more. Clients post jobs; workers register profiles and respond to job posts.

Multilingual: English, Russian, Hebrew (RTL).

## Stack

- Next.js 14 (App Router)
- Tailwind CSS
- Client-side demo data store (localStorage) — swap for a real backend when ready

## Dev

```
npm install
npm run dev
```

## Roadmap

- Backend + real auth (workers / clients accounts)
- Email + Telegram + WhatsApp notifications:
  - Notify client when a worker responds to their offer
  - Notify workers when a matching job is posted
